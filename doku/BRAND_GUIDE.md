# SegmentJoinPilot Brand Guide

## Concept

The mark shows two separated model segments and a central prism-shaped alignment connector. The symbol should communicate the complete workflow without requiring text: split, align, and assemble.

## Colors

| Role | Color | Hex |
|---|---|---|
| Primary dark | Deep navy | `#142B4A` |
| Model geometry | Technical cyan/teal | `#20B8C5` |
| Connector accent | Orange | `#F28C28` |
| Contrast | White | `#FFFFFF` |

## Usage

- Use the banner at the top of the GitHub README.
- Use the horizontal logo on documentation, web pages, and release material.
- Use the icon-only files for Fusion commands and compact UI placements.
- Prefer the largest available source and scale down for additional sizes.
- Keep sufficient clear space around the symbol.

## Avoid

- recoloring individual parts without updating the brand palette
- stretching or changing the aspect ratio
- placing the logo on a low-contrast cyan or orange background
- adding Autodesk or Fusion logos to the mark
- adding thin details that disappear in the 16-pixel icon

## Generation record

The artwork was generated with the built-in image-generation workflow from a custom prompt. It intentionally uses generic CAD geometry and does not reproduce Autodesk branding.
